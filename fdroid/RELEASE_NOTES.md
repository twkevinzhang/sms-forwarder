SMS Forwarder forwards new SMS using separately selected receiving and sending SIMs.

Version 1.0.1 enables R8 release optimization and prepares upstream-signed Reproducible Builds. The upstream-signed APK is published only after independent rebuilding and signature-copy verification succeed.

Approved releases will provide an upstream-signed APK and SHA-256 file. F-Droid independently rebuilds and verifies the APK before distributing the developer-signed version. Official repository inclusion and publication remain subject to F-Droid review. Unsigned Actions artifacts are not installable distribution packages. Version 1.0.0 was a source-only release and remains unchanged.

Mobile operator SMS charges apply. Device background restrictions may prevent forwarding or delay status reports. See README for permissions and limitations.
