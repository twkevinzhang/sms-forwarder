SMS Forwarder forwards new SMS using separately selected receiving and sending SIMs.

Installation is intended through the official F-Droid repository after inclusion and successful publication. A GitHub tag or Release does not mean F-Droid has accepted or published the version. F-Droid builds from source and signs its own APK; the unsigned Actions build artifact is a build candidate, not an installable distribution.

Mobile operator SMS charges apply. Device background restrictions may prevent forwarding or delay status reports. See README for permissions and limitations.
